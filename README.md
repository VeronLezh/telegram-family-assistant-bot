# 🤖 Family Assistant Bot

> **Демо-версия для портфолио.** Это анонимизированная копия личного проекта, который реально работает в семье автора. Все имена, Telegram ID, email и ID календарей — вымышленные демо-данные, подробнее см. [раздел «Об анонимизации»](#об-анонимизации).

Асинхронный Telegram-бот на Python, который заменяет собой семейный органайзер: ведёт расписание занятий и тренировок, шлёт напоминания, отвечает на вопросы через LLM (текстом и голосом), синхронизируется с Google Calendar и Google Sheets.

Проект написан «для себя» и находится в активном использовании — это не учебный туториал, а рабочий инструмент с реальными пользователями (семьёй из 4 человек), которым он экономит время каждый день.

## Зачем этот проект в портфолио

Показывает, как я:

- проектирую асинхронное Python-приложение поверх `python-telegram-bot` с несколькими независимыми периодическими джобами (`JobQueue`);
- интегрирую LLM (Groq: `qwen/qwen3-32b` для чата, `whisper-large-v3-turbo` для распознавания голоса) в реальный продуктовый сценарий — не просто чат-бот, а парсинг естественного языка в структурированные действия (добавление напоминаний, событий календаря, тренировок);
- работаю с внешними API (Google Calendar, Google Sheets, Make.com webhooks) и строю ролевую модель доступа поверх Telegram user ID;
- держу код читаемым и небольшим — разделение на `handlers/`, `services/`, `reminders/` вместо одного файла на 2000 строк;
- думаю о безопасности: секреты только через env vars, никаких токенов в коде (см. `.env.example`).

## Возможности

- **AI-чат** с контекстом разговора (до 10 сообщений на пользователя), поддержка текста, голосовых сообщений и фото
- **Расписание** занятий и тренировок по дням и по членам семьи — редактирование командами и обычным текстом на естественном языке («убери тренировку по вторникам»)
- **Напоминания**: разовые, ежедневные, ежемесячные, «умные» (динамически формулируются AI) и алерт о перегруженном дне
- **Список подарочных пожеланий** с AI-парсингом сообщений в список и автонапоминанием остальным членам семьи перед днём рождения
- **Google Calendar**: просмотр событий, добавление событий из чата, отдельно личный и семейный календарь
- **Рассылка** сообщений всем пользователям (только для админа)
- **Inline-режим** бота в Telegram

## Стек

| Слой | Технология |
|---|---|
| Язык / рантайм | Python 3.11+, asyncio |
| Telegram | [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) v21+ (async API), `JobQueue` для периодических задач |
| LLM / STT | [Groq](https://groq.com/) — `qwen/qwen3-32b` (чат, парсинг), `whisper-large-v3-turbo` (голос → текст) |
| Календарь | Google Calendar API (service account) |
| Таблицы | Google Sheets API |
| Healthcheck | Flask, поднимается в отдельном daemon-потоке |
| Интеграции | Make.com (webhook) |
| Деплой | Render (worker, `Procfile`) + UptimeRobot пингует `/health`, чтобы инстанс не засыпал |

## Архитектура

```
bot.py              — точка входа: регистрация хендлеров, job queue, polling-цикл с реконнектом
config.py           — пользователи, права доступа, ID календарей, AI-промпты (см. env vars ниже)
server.py           — Flask healthcheck-сервер

handlers/            — обработка входящих апдейтов Telegram
  messages.py         — текст, голос, фото → AI
  schedule.py          — расписание занятий
  trainings.py         — расписание тренировок
  menu.py               — главное меню (inline-кнопки)
  admin.py               — help-команды для админа
  inline.py                — inline mode

services/            — интеграции с внешним миром
  ai.py                — Groq: чат, парсинг напоминаний, транскрипция голоса
  calendar.py            — Google Calendar API
  sheets.py                — Google Sheets API

reminders/            — доменная логика напоминаний
  jobs.py                — периодические задачи (тренировки, напоминания, ДР, busy-day алерт)
  storage.py                — персистентность напоминаний
  personal.py                 — персональные напоминания пользователей
  wishlist.py                   — список подарочных пожеланий
```

Ключевые архитектурные решения:

- **Права доступа только через Telegram user ID** — списки `ADMIN_USERS` / `CALENDAR_PERSONAL_USERS` / `CALENDAR_FAMILY_USERS` в `config.py`, без внешней системы авторизации — это осознанное упрощение для приватного бота с 4 известными пользователями.
- **Всё время — Europe/Moscow** (`config.MOSCOW_TZ`), чтобы не путаться с UTC в напоминаниях и календарных событиях.
- **AI-промпты привязаны к пользователю** (`AI_PROMPTS_BY_USER`) — у каждого свой тон общения с ассистентом.
- **История чата — in-memory**, без БД: осознанный компромисс сложность/нужность для проекта такого масштаба.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # и заполнить своими значениями
python bot.py
```

Бот стартует в режиме polling, Flask healthcheck поднимается автоматически в фоновом потоке.

### Переменные окружения

См. `.env.example`:

- `BOT_TOKEN` — токен Telegram Bot API
- `GROQ_API_KEY` — ключ Groq API
- `MAKE_WEBHOOK_URL` — webhook Make.com (опционально)
- `PORT` — порт Flask healthcheck (по умолчанию 5000)

Для Google Calendar / Sheets также нужен файл сервисного аккаунта Google (JSON) — в демо-репозитории он не публикуется, положите свой в корень проекта и укажите путь в `services/calendar.py` / `services/sheets.py`.

## Об анонимизации

Это выгруженная в отдельный репозиторий копия личного семейного бота. Из неё убраны и заменены:

- реальные Telegram ID пользователей → `111111111`, `222222222`, `333333333`, `444444444`
- реальные имена → Анна, Борис, Виктор, Галя
- реальные ID Google-календарей → `example@gmail.com`, `family_calendar_id@group.calendar.google.com`
- реальные даты рождения → вымышленные
- файл сервисного аккаунта Google и `.env` с секретами — не публиковались никогда, в этом репозитории их нет

Код и архитектура — без изменений, это тот же проект, что работает в проде.
